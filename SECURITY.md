# Security

If you think you have found a security problem in jsflow (the service, the dashboard, the SDK or our websites), **do not open
an issue or a discussion.** Email **support@jsflow.com**, or follow the instructions in
https://jsflow.com/.well-known/security.txt. How we handle reports, what testing is welcome, and what to include:
https://jsflow.com/docs/security/reporting/.

We confirm receipt within 3 working days and keep you informed until the problem is fixed or closed.

If you pasted a secret key (`sk_…`) anywhere public, revoke it in the dashboard immediately and create a new one.
